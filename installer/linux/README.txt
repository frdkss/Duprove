Duprove для Linux (tar.gz)

1. Распакуйте архив целиком в отдельный каталог.
2. Откройте в этом каталоге терминал и выполните: bash install.sh
3. Прочитайте сведения о данных. Enter продолжает установку; Ctrl+C отменяет её.

Установка выполняется без sudo для текущего пользователя:
  приложение: $XDG_DATA_HOME/duprove (обычно ~/.local/share/duprove)
  команда: ~/.local/bin/duprove
  ярлык: $XDG_DATA_HOME/applications/duprove.desktop

Повторный запуск install.sh обновляет только файлы программы. Предварительно
закройте Duprove. Настройки Electron и отчёты не удаляются. Если каталог назначения
или команда заняты другим приложением, установщик остановится.

Для автоматической установки: bash install.sh --non-interactive
Информация о данных выводится и в этом режиме, до копирования файлов.

Анонимная статистика включена по умолчанию для нового профиля. Её можно отключить
в настройках; ранее сохранённый отказ сохраняется. Установщик не меняет этот выбор.

Нужны Bash, стандартные утилиты GNU и графические библиотеки, необходимые Electron.
Архив предназначен для указанной в имени архитектуры и Linux с glibc (не musl).
Установщик не добавляет --no-sandbox и не изменяет системные настройки Chromium.
Если система запрещает пользовательские пространства имён, запуск Electron может
требовать настройки политики системы администратором.

Для удаления закройте программу и удалите только перечисленные выше файлы/каталог
приложения. Профиль с настройками и результатами хранится отдельно.
