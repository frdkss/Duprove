Численные параметры трёх режимов нагрузки ещё не определены.

- Символические ссылки не обходятся; жёсткие ссылки на один физический файл не увеличивают количество файлов и дубликатов.

- [ ] **GR-06. Добавить постраничную выдачу.** Ограничить число групп и участников в одном ответе. Готово: можно открыть любую страницу большой группы без загрузки всего каталога в память и без блокировки основного процесса.

### 2.2. Экран групп и выбор оригинала

- [ ] **UI-01. Добавить вход в результаты.** Показать кнопку «Группы файлов» после завершения анализа. Готово: неполный результат явно обозначен; при отсутствии сохранённого каталога предлагается новый анализ.
- [ ] **UI-02. Показать список групп.** Добавить разделы «Точные дубликаты» и «Похожие файлы», количество и навигацию по страницам. Готово: пустое состояние и ошибки загрузки имеют понятные сообщения.
- [ ] **UI-03. Показать участников выбранной группы.** Отобразить полные пути, размеры и доступность; разрешить копирование пути. Готово: длинные пути и одинаковые имена в разных каталогах различимы.
- [ ] **OR-01. Добавить выбор сохраняемого экземпляра.** Выбирать оригинал явно по пути; не назначать его автоматически по имени или дате. Готово: в одной группе выбран максимум один оригинал, пользователь может изменить выбор.
- [ ] **OR-02. Сохранить выбор локально.** Привязать его к идентификатору анализа и файла. Готово: выбор переживает перезапуск; новый анализ не наследует решения по случайно совпавшим числовым ID.
- [ ] **OR-03. Защитить оригинал.** Запретить его удаление и учесть пересечение точных групп с похожими парами. Готово: файл, сохраняемый в одной группе, нельзя удалить через другую без пересмотра выбора.

### 2.3. Решения и ручная проверка

- [ ] **RV-01. Добавить состояния решения.** Различать «Не решено», «Оставить», «Проверить вручную», «Отмечен для удаления» и «В корзине». Готово: выбор решения сам по себе не удаляет файл.
- [ ] **RV-02. Сохранять решения отдельно от доказательств анализа.** Не переписывать исходные хеши и результаты сравнения пользовательским вердиктом. Готово: после перезапуска видны решения, а статистика сканирования остаётся объяснимой.
- [ ] **PV-01. Определить форматы предпросмотра.** Отдельно описать поддержку TXT/Markdown, DOCX, PNG/JPEG и поведение остальных форматов. Готово: для каждого формата определены вид просмотра, ограничения размера/декодирования и сообщение об отсутствии поддержки; PDF/аудио/видео не заявлены без реализации.
- [ ] **PV-02. Добавить безопасный просмотр текста.** Показывать текст внутри приложения без исполнения HTML, скриптов, макросов и внешних ссылок. Готово: есть предел чтения, указание усечения и обработка неподдерживаемой кодировки.
- [ ] **PV-03. Добавить извлечение текста DOCX.** Использовать ограниченный разбор архива и XML без исполнения активного содержимого. Готово: большие и повреждённые архивы отклоняются; пользователь понимает, что оформление может не отображаться.
- [ ] **PV-04. Добавить просмотр PNG/JPEG.** Ограничить размер входного файла, число декодированных пикселей и память. Готово: повреждённое или слишком большое изображение даёт ошибку без зависания приложения.
- [ ] **PV-05. Добавить сравнение двух экземпляров.** Открывать оригинал и проверяемый файл рядом с их полными путями. Готово: видно, к какому файлу относится каждый предпросмотр; при отсутствии поддержки полноценного просмотра это явно сообщается.
- [ ] **RV-03. Добавить вердикт после просмотра.** Дать действия «Оставить» и «Считать дубликатом / отметить для удаления». Готово: вердикт меняет только локальное решение; для похожих файлов требуется явная ручная проверка обоих экземпляров.

### 2.4. Перенос в корзину

- [ ] **DL-01. Выделить отдельную команду удаления.** Принимать только идентификаторы текущего анализа, группы и файла; пути получать из доверенного локального каталога. Готово: renderer не может передать произвольный путь для удаления.
- [ ] **DL-02. Добавить подтверждение.** Перед переносом показать путь удаляемого файла и сохраняемого оригинала, отмену выбрать по умолчанию. Готово: отмена не меняет файл; для похожей пары указано, что содержимое может различаться.
- [ ] **DL-03. Перепроверить оригинал и дубликат после подтверждения.** Проверить тип, идентичность, размер, времена и актуальное содержимое; для точных дубликатов подтвердить совпадение. Готово: изменение, замена, исчезновение или недоступность любого экземпляра отменяют операцию.
- [ ] **DL-04. Проверить пути и ссылки.** Проверить границы выбранных корней, исключения, символические ссылки и junction; оценить гонку между проверкой и операцией ОС. Готово: небезопасный путь отклоняется; пределы защиты от внешней подмены пути задокументированы, атомарность не заявлена без доказательства.
- [ ] **DL-05. Подключить системную корзину.** Реализовать адаптер ОС, например `shell.trashItem` в Electron. Готово: при недоступной корзине или отказе доступа операция завершается ошибкой; безвозвратное удаление не используется как запасной вариант.
- [ ] **DL-06. Обрабатывать результат каждого файла.** Записывать успешный перенос только после ответа ОС, показывать ошибку отдельно. Готово: частичный сбой не выдаётся за полный успех, повторная команда не удаляет уже обработанный файл.
- [ ] **DL-07. Заблокировать конфликтующие операции.** Согласовать удаление с новым анализом, продолжением, обновлением и завершением приложения. Готово: каталог не пересоздаётся во время подтверждения или переноса; выбранный оригинал не меняется конкурентной командой.
- [ ] **DL-08. Обновить отображение результата.** Помечать перенесённые файлы во всех пересекающихся группах. Готово: UI отличает исходную статистику анализа от состояния после действий; способ пересчёта явно определён.

- [ ] **QA-02. Проверить защиту операций.** Проверить подмену IPC, защиту оригинала, отмену, изменение файлов после анализа/предпросмотра/подтверждения, ссылки, отказ корзины и частичный сбой. Готово: ни одна отрицательная проверка не удаляет непредназначенный файл.
- [ ] **QA-03. Проверить предпросмотр.** Проверить активный HTML как текст, повреждённые изображения/DOCX, архивы с чрезмерной распаковкой, лимиты и неподдерживаемые форматы. Готово: содержимое файлов не исполняется, ошибки не завершают приложение.

Готово: подтверждены клавиатура, фокус, светлая/тёмная темы и размеры окна вплоть до 640×480; реальные и имитированные операции в отчёте разделены.
