# Duprove

Школьный проект ученика 10 класса, Сивакова Фёдора Юрьевича
Программа для обнаружения дубликатов файлов в ОС, с возможностью архивации, слияния, удаления и ручной проверки подозрительных файлов.

Итерация 2 добавляет локальные группы файлов, явный выбор сохраняемого оригинала,
решения, отдельное окно просмотра и сравнения нескольких файлов и перенос отмеченных копий в
системную корзину после отдельного подтверждения. Архивация и слияние пока не реализованы.
Сам анализ читает файлы и сохраняет служебные данные; выбор решения файл не меняет.
UI позволяет выбрать накопители, просмотреть их объём, выбрать режим
нагрузки и светлую/тёмную тему, открыть настройки и справку. Доступны запуск, пауза,
остановка и ручное продолжение после перезапуска, прогресс и диаграммы по дискам,
дополнительная проверка содержания. Во время задания крестик скрывает окно в трей.
Недоступные параметры настроек отключены. Логотип — `public/logo.svg`.
Из него автоматически создаются `public/logo.ico` и `public/logo.png` для окна,
панели задач и упакованного приложения. Генерация выполняется при сборке,
запуске разработки и через `service.bat`; отдельно — `npm run icons`.

После завершения анализа кнопка «Группы файлов» открывает точные дубликаты.
Слева находятся фильтры с галочками: при открытии ничего не выбрано. Можно выбрать
несколько групп или «Выбрать всё». Поиск и «Выбрать всё» закреплены при прокрутке,
группы и файлы подгружаются без страниц. Поиск сохраняет выбранные фильтры:
обычный текст ищет часть имени или расширения, `"имя.txt"` — полное имя,
`"при"*.tx*` — имена на «при» с расширением на `.tx`.
«Выбрать всё» действует на найденные группы, включая ещё не подгруженные.
Оригинал — ваш выбор экземпляра для сохранения, а не
утверждение о времени создания файла. Он защищён от переноса также в других
пересекающихся группах. «Открыть» показывает один файл в отдельном окне,
«Сравнить с оригиналом» — пару. Чекбоксы и «Сравнить выделенные» открывают
несколько участников группы; оригинал тоже можно выделить для сравнения.
На FHD помещается до четырёх документов, на HD — два или три; остальные доступны
через горизонтальную прокрутку и стрелки вверху окна.
Выбранный оригинал закреплён слева; прокручиваются только остальные файлы.
При сравнении нескольких файлов оригинал добавляется автоматически, если его
не отметили в списке. При смене оригинала закреплённая колонка обновляется.
Для точных дубликатов выберите оригинал, отметьте другие экземпляры чекбоксами и
нажмите «Перенести выделенные в корзину». Выбор файлов сохраняется при подгрузке
списка; сравнение и перенос выполняются отдельно для каждой группы.
Можно также использовать «В корзину» у отдельного отмеченного файла.
В подтверждении отмена выбрана по умолчанию. Перед переносом
программа перепроверяет оба файла. Ошибка корзины не приводит к безвозвратному удалению.

Каталог последнего результата хранится локально в
`userData/analysis/results/catalog.sqlite` до 30 дней (проверка срока при обращении),
не более 128 МиБ, и сохраняется отдельно от очищаемой рабочей базы. Новый анализ
не наследует решения прежнего. Пути, предпросмотр, оригиналы и решения в
статистический отчёт не добавляются. Счётчики диаграмм описывают исходное
сканирование; состояние после действий видно у участников групп.
Python, TXT, Markdown, HTML и другие текстовые файлы открываются в текстовом
редакторе для чтения с выбором размера шрифта и переноса строк. PDF отображается
постранично с масштабом, изображения — с масштабом, аудио/видео — с управлением
воспроизведением. DOCX и RTF отображают оформление, старый DOC — извлечённый текст.
Таблицы XLSX/XLS/ODS/CSV позволяют переключать листы и просматривать ячейки.
Макросы, скрипты и формулы не исполняются. Это просмотрщики: сложное оформление
может отличаться от Word/Excel, а поддержка медиа зависит от кодеков Electron.
Защищённый или неподдерживаемый вариант формата показывает ошибку.
Для чтения создаётся проверенная локальная копия; исходник не меняется.
Копии ограничены 2 ГиБ на окно и очищаются при его закрытии или следующем запуске.
Текст, Word и таблицы ограничены 64 МиБ (DOC — 32 МиБ), распакованные части
архивного документа — 128 МиБ. Ограничения и выполненные проверки:
[docs/file-viewers.md](docs/file-viewers.md).

При ширине до 1280 px интерфейс масштабируется через `rem`. В более широких окнах размеры текста, кнопок и бокового меню сохраняются, увеличивается рабочая область;
минимальный размер окна — 640×480. Карточка диска одновременно переключает галочку
и отображаемый обзор. Стрелки переключают только выбранные диски в порядке списка,
не меняя галочки. У первого диска нет стрелки назад, у последнего — вперёд;
при выборе одного диска обе стрелки скрыты.
«Выбрать всё» находится над списком; списки дисков и режимов плавно раскрываются.
Список накопителей остаётся только в боковом меню. При раскрытии режимов
центральная область целиком отведена обзору выбранного диска.
«Помощь» открывает `https://duprove.site/#instrucitons` в системном браузере.

В Windows можно запустить **`service.bat`**: пункт **1** устанавливает зависимости,
**2** собирает и запускает с логом, **3** — без сервисных логов.
Меню и дополнительные команды описаны в [service/README.md](service/README.md).

отказ сохраняется. Окон при запуске и подтверждений
при отключении нет. Выбор сохраняется на устройстве; старые отчёты после отзыва

подключён; без настроенного адреса отчёты остаются локально. Установщик Windows показывает информацию о данных без отдельного
подтверждения согласия. Подробности и границы реализации: [docs/consent.md](docs/consent.md).

Для разработки нужны Node.js 24, Python 3.12+, CMake 3.24+, C++17-компилятор
(Windows: Visual Studio Build Tools с Desktop development with C++; Linux: GCC/Clang).
Первичная установка зависимостей требует интернета, запуск установленного приложения — нет.

```sh
npm ci
python -m venv .venv
```

Активировать окружение: Windows PowerShell — `.venv/Scripts/Activate.ps1`,
Linux — `source .venv/bin/activate`. Затем на обеих платформах:

```sh
python -m pip install -r backend/requirements.txt
npm run native:configure
npm run native:build
npm run build
npm test
npm run test:backend
npm run test:server
npm run test:native
npm run test:statistics
npm run test:traversal
npm run test:comparison
npm run test:content
npm run test:local-files
npm run test:results-ui
npm run test:results-integration
npm run test:results-privacy
npm run test:resume
npm run test:runtime
npm run test:desktop
ctest --test-dir build/native -C Release --output-on-failure
npm start
```

`npm run dev` запускает Vite и Electron для разработки. C++ нужно предварительно
собрать командами выше. `test:native` использует временные искусственные файлы,
а не накопители пользователя. CI настроен на сборку и проверки Windows, Linux и macOS
(Intel/Apple Silicon).
Наличие CI-конфигурации само по себе не подтверждает прохождение удалённого запуска.
Канал обновлений из GitHub Releases, подпись пакетов и границы проверенной установки:
[docs/auto-updates.md](docs/auto-updates.md). Сквозная проверка между опубликованными
версиями ещё не завершена.
`npm run test:ui` проверяет Electron/preload/React на искусственных накопителях
и сохраняет снимки экранов в `.verification/ui-*.png`; на Linux нужен графический сеанс
или Xvfb. Результаты локальной проверки: [docs/verification.md](docs/verification.md).
`test:resume` проверяет сохранение хешей после прерывания и актуальность кэша,
`test:runtime` — границы обработки содержания в режимах нагрузки,
`test:desktop` — скрытие окна в трей и завершение приложения; ему также нужен
графический сеанс. Замеры ресурсов: `python tests/benchmark_analysis.py`.

## ZIP с исходниками программы

```sh
npm run pack:source
```

Архив создаётся в `source-archives/Duprove-source-<дата-время>.zip`.
Нужен Python 3.12+; дополнительные пакеты и установленные `node_modules` не требуются.
Прямой запуск из любой папки: `python <путь-к-проекту>/scripts/pack-source.py`.
Свой путь: `python scripts/pack-source.py --output D:/archives/Duprove-source.zip`.
Существующий архив не перезаписывается.

Внутри: C++-ядро (`native/src`), логика Electron (`electron`), React-интерфейс
и стили (`src`), общие контракты, ресурсы (`public`), публичный ключ обновлений,
скрипты применения обновлений, минимальные файлы сборки и лицензия.
Сохраняются текущие файлы с диска, включая ещё не закоммиченные изменения.
Сервер `backend`, служебное меню `service`, тесты, фикстуры, документация,
зависимости, сборки, кеши, логи, базы данных и `.env` исключены.
Это архив исходников настольной программы; для сборки ядра без исключённых тестов
нужно передать CMake параметр `-DBUILD_TESTING=OFF`.
