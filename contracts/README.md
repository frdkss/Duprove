# Контракт статистики v1

`report.schema.json` — единственный источник структуры отчёта для Electron (Ajv)
и Python (jsonschema). Схема draft-07 запрещает неизвестные поля на всех уровнях.
Дополнительные арифметические проверки находятся в `validate.ts` и
`backend/duprove_backend/contract.py`; обе реализации проверяются одним набором примеров.

Все счётчики — целые числа от 0 до 9007199254740991 (точный диапазон JavaScript).
В разреженных распределениях присутствуют только положительные количества.
`schema_version = 1`. `complete = false` означает частичный результат, а не успешный анализ.

Необязательное расширение v1 добавляет `file_bytes` и `duplicate_bytes` во все
сводки, `size_bytes` (размер одного участника) в группы и `reclaimable_bytes`
в общий итог. Эти поля должны присутствовать совместно; проверяются суммы и
произведения размеров и числа копий. Старые отчёты без них остаются допустимыми.
В итогах и дисках могут также присутствовать `capacity_bytes`, `available_bytes`,
`used_bytes` с проверкой `capacity_bytes = available_bytes + used_bytes` и суммы
по дискам. `progress` содержит время снимка, статус и работу каждого диска без
путей и имён файлов. Подробные определения — в [statistics.md](../docs/statistics.md).

- `statistics.total`: файлы, пустые файлы, типы, участники групп, число групп,
  лишние копии. `duplicates = sum(copies - 1)`, `duplicate_members = sum(copies)`.
- `statistics.disks`: те же счётчики, кроме лишних копий, с локальными номерами
  `id = 0..N-1`, которые действуют только внутри отчёта. Нет путей, меток томов,
  серийных номеров и постоянных идентификаторов.
- `statistics.locations.standard`: общие итоги и шесть обязательных категорий:
  downloads, documents, videos, pictures, music, desktop.
- `statistics.locations.custom`: единый итог остальных папок без имён и структуры.
- `duplicates`: точные группы с `copies >= 2`, `duplicates = copies - 1`,
  распределениями `extensions`, `disks`, `categories`; сумма каждого распределения
  равна `copies`. Внутренние идентификаторы, пути и хеши не включаются.

В каждой сводке `files = sum(types)`, `empty = types.empty` (либо 0),
`duplicate_members <= files - empty`. Все сводки согласуются с группами.
Количество групп по дискам и категориям **не складывается**: одна группа может
пересекать несколько категорий. В сводном итоге она учитывается один раз.
Лишние копии пока считаются только глобально: выбор оригинала и распределение
`N - 1` между дисками/категориями в этапе 0 не определены.

Тип — нормализованное расширение (`.jpg`, `.tar.gz`, `.my_format`, `.данные`),
`none` или `empty`. Длинные и нестандартные расширения сохраняются буквально,
до 255 символов; разделители пути и NUL запрещены. ASCII-буквы приводятся к нижнему
регистру. `other` принимается только для совместимости со старыми отчётами;
новый анализ его не создаёт.
`empty` исключён из групп. Прототип распознаёт `.tar.gz`, `.tar.bz2`, `.tar.xz`,
`.tar.zst`; окончательный список ещё не согласован. Доли диаграмм вычисляются
локально как `types[type] / files`; при `files = 0` доля равна 0.

Схема v1 не содержит `warn`: предупреждения этапа 4 выдаются отдельно в локальном
`result.content` и считаются парами. Их проверяет `contracts/content.ts`; они не
входят в отправляемую статистику. Критерии — в `docs/file-comparison.md`.
Расширения имеют ограниченную длину и алфавит, но произвольный текст, похожий
на расширение, невозможно отличить от настоящего расширения одной схемой.
Граница приватности обеспечивается явной сборкой отчёта из агрегатов в C++,
а не пересылкой внутренних объектов с удалением известных опасных полей.

`contracts/analysis.ts` описывает отдельный локальный протокол выполнения.
Необязательное `DiskProgress.issues` хранит сгруппированные диагностические
коды, операции и счётчики. `examples` оставлено пустым для совместимости;
старые примеры путей очищаются при чтении. Диагностика не является полем отчёта
v1 и не передаётся статистическому транспорту; старые снимки без неё допустимы.
Подсчёт, сохранение и границы приватности этапа 6: [statistics.md](../docs/statistics.md).

`fixtures/` содержит **искусственные тестовые данные**, не результаты анализа
пользовательских накопителей. Несовместимое изменение структуры требует новой версии контракта.
