# Просмотр и массовое сравнение файлов

Основание: текущие исходники и локальные запуски тестов 25.10.2026.

В результатах «Открыть» показывает один файл в отдельном окне Electron.
«Сравнить с оригиналом» открывает пару; чекбоксы и «Сравнить выделенные» —
несколько участников группы, включая оригинал. Окно переиспользуется,
имеет собственные кнопки управления и горизонтальную прокрутку со стрелками.
При 1920 px видны четыре документа, при 1366 px — три, при 1280 px — два.
Выбранный оригинал занимает неподвижную первую колонку слева, вне горизонтально
прокручиваемой области. При смене оригинала в ней появляется новый выбранный
файл. Если для сравнения отмечены несколько копий без оригинала, он добавляется
как отдельный опорный документ; одиночная команда «Открыть» остаётся одиночной.
На минимальной ширине 640 px оригинал и одна копия остаются рядом.

| Содержимое | Просмотрщик |
| --- | --- |
| Python и прочие текстовые файлы | Текстовый редактор для чтения; UTF-8/UTF-16, резервная Windows-1251, размер шрифта и перенос строк |
| PDF | PDF.js, страницы и масштаб, локальные шрифты/CMAP/WASM без CDN при просмотре |
| Аудио и видео | Элементы Electron/Chromium с воспроизведением и перемоткой; кодеки зависят от среды |
| Изображения | Масштабирование; TIFF декодируется отдельно |
| DOCX и RTF | Отрисовка документа, изолированная от оформления приложения |
| Word 97–2003 DOC | Извлечённый текст документа, заголовков и сносок |
| XLSX, XLS, ODS, CSV и другие распознаваемые таблицы | Листы, значения ячеек, страницы по 100 строк и 50 столбцов |

Это просмотрщики, а не полноценные Word/Excel: сложная вёрстка может отличаться.
Формулы, макросы и скрипты не исполняются. Защищённый, двоичный или
неподдерживаемый вариант формата показывает ошибку.

Renderer передаёт ID анализа, группы и файлов. Worker проверяет членство в группе,
а нативный помощник — идентификатор, размер и временные метки источника до и после
копирования. Отдельная проверенная копия получает SHA-256; renderer не получает её
служебный путь. Протокол с идентификатором окна поддерживает диапазоны байтов для
PDF и медиа. Исходные файлы при просмотре не меняются.

Предел копий — 2 ГиБ на окно, свободное место учитывается с резервом 512 МиБ.
Для текстового/Word/табличного парсера вход ограничен 64 МиБ, для DOC — 32 МиБ,
распакованные ZIP-части ограничены 128 МиБ и 8192 записями, TIFF — 16 млн пикселей.
Копии удаляются при смене набора/закрытии окна; после аварийного выхода очистка
повторяется при запуске. Видимые документы загружаются по мере прокрутки.

Массовый перенос точных дубликатов требует выбора оригинала и чекбоксов других
участников группы. Кнопка сама отмечает выбранные экземпляры для переноса и
показывает отдельное подтверждение. Для похожих файлов остаётся ручной вердикт
после загрузки обоих документов в окне сравнения. Нативная повторная проверка
содержимого, защита оригинала и системная корзина сохраняются.
Во время переноса список не перезагружается по промежуточным уведомлениям;
после операции он обновляется вместе с результатом.

## Фильтры групп и прокрутка

Вместо кнопки одной активной группы используется список фильтров с чекбоксами.
При каждом открытии окна фильтры и файлы не выбраны. Несколько выбранных фильтров
показывают несколько блоков файлов справа, с независимым оригиналом, сравнением
и переносом в каждом блоке. Вкладки похожих текстов и изображений из окна убраны;
правила проверки содержания и сохранённые результаты анализатора не меняются.

Поиск и «Выбрать всё» закреплены сверху левого списка. Оба списка подгружаются
при прокрутке без кнопок страниц. Поиск работает по наиболее частому полному
имени группы, включая расширение, и не сбрасывает выбранные фильтры или файлы.
Обычный запрос ищет часть имени без учёта регистра; `"имя.txt"` — точное полное
имя; `*` вне кавычек заменяет любую последовательность символов. Пример
`"при"*.tx*` находит `привет.txt` и `пример.txz`. Остальные символы трактуются
буквально, регулярные выражения и SQL не выполняются. Незакрытые кавычки
показывают подсказку.

«Выбрать всё» выбирает найденные текущим поиском группы, включая ещё не
подгруженные. Индивидуальное снятие галочки и следующий поиск сохраняются.
Для этого передаются правила выбора, а не все пути/участники каталога.
Частые имена групп вычисляются один раз и сохраняются в локальном каталоге.
Галочки на карточках файлов остаются отдельным выбором для действий.
Панель текущей группы с названием, выбором оригинала, сравнением и корзиной
закреплена сверху списка. При прокрутке к следующей группе её заменяет панель
этой группы. Проверка Electron включает настоящий клик по закреплённой кнопке
сравнения в конце списка из 60 файлов без возврата прокрутки наверх.
Для сравнения можно выделить до 32 файлов, дополнительно показывается оригинал,
если он не был выделен. Предел одного запроса корзины — 1 000 файлов,
дополнительно действует существующий предел длины подтверждения с путями.
