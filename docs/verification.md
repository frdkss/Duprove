- Python backend через stdin принял корректный искусственный отчёт.

  отсутствие Node в renderer, доступность узкого preload API и отсутствие
  горизонтального переполнения проверены на искусственном накопителе.

  использует стандартное окно. Runtime Electron установлен из официального архива

## Адаптивность и взаимодействия — 2026-10-14

Основание для масштабирования: локальные файлы Nodagora
`desktop/ui/windows/main/css/main.css` и `desktop/main/windows/main-window.ts`.
Duprove использует пропорциональные `rem` от макета 1280 px и минимум окна 640×480.
Размер кольца дополнительно зависит от высоты рабочей области; длинные списки
и настройки прокручиваются. Кнопки управления окном сохраняют обычный размер.

Сборка и UI-проверка прошли на трёх искусственных дисках. Проверены выбор всей
карточкой, совпадение галочки и обзора, снятие выбора, общий и частичный выбор,
стрелки назад/вперёд с переходом через край списка, промежуточная высота анимации
сворачивания и разворачивания, недоступность скрытых списков для фокуса,
подсказка при наведении и hover всей карточки в тёмной теме.
Снимки проверены при 1280×800, 960×640, 640×480, 1920×1080 и 1280×480.
Горизонтальное переполнение и обрезание недоступного для прокрутки заголовка
проверяются автоматически. Скриншоты находятся в `.verification/ui-*.png`.

Проверка настоящего main/preload подтверждает минимальный размер окна,
видимость и управление окном. Для справки `shell.openExternal` подменяется
регистратором вызовов: подтверждён точный URL `https://duprove.site/#instrucitons`.
Содержимое сайта и доступность его раздела этой проверкой не подтверждаются.
Тесты используют отдельные профили Electron в `.verification/`.

При первоначальной записи теста PowerShell заменил кириллицу на `?`, что вызвало
ошибку синтаксиса регулярного выражения. Тест исправлен в UTF-8; команда `test:ui`
теперь проверяет синтаксис Node до запуска Electron.
