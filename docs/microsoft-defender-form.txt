I am the author of Duprove, a personal school project developed by me as an individual student. I am not representing a company.

Duprove is an open-source duplicate-file analysis application, licensed under GPL-3.0-only. The Windows desktop application uses Electron, TypeScript and React, with a bundled C++17 analyzer.

The user selects drives and starts a scan. The analyzer reads file names, paths, sizes, timestamps and file bytes to calculate SHA-256 hashes and verify duplicates. Optional content comparison parses supported text documents and images. Scanned files are not modified, deleted, moved or encrypted. File metadata and hashes are stored locally in a SQLite working index under the user's application-data directory.

The native analyzer has no implemented network client. A separate Electron module can send aggregate file/duplicate statistics to a configured HTTPS endpoint. This setting is enabled by default and can be disabled in Settings. Reports exclude file contents, names, full paths and hashes. Without a configured endpoint, statistics remain local.

Supported installations also check GitHub for updates and verify signed update metadata and package hashes. A bundled PowerShell helper applies Windows updates.
