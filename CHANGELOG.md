# История изменений

## 2.1.1 — 2026-10-29 (не опубликовано)

### Исправлено

- Ошибки открытия, чтения, получения метаданных и проверки актуальности файла
  приводят к его пропуску до конца текущего запуска. Проверка остальных файлов
  продолжается; одна ошибка файла больше не делает весь анализ незавершённым.
- Пропущенные файлы исключаются из статистики, точных совпадений, результатов
  проверки содержимого и итогового локального каталога. Сохранённый хеш такого
  файла удаляется. Ошибка остаётся в журнале и учитывается один раз за запуск.
- Недоступные вложенные папки и непрочитанные части списков файлов пропускаются
  без остановки обработки остальных каталогов.
- Ошибка преобразования имени файла в UTF-8 не обрывает обход соседних файлов.
- После исключения файлов заново рассчитываются счётчики файлов, пустых файлов
  и расширений. Счётчики проверки содержимого согласованы с общей статистикой.
- Известная причина остановки, включая нехватку места, сохраняется после
  перезапуска приложения.

### Изменено

- Вместо фиксированных пределов рабочей базы 512 МиБ и временных таблиц SQLite
  256 МиБ используются пределы по доступному месту. Уже выделенные страницы
  учитываются, резерв свободного места 512 МиБ сохранён.
- Журнал поясняет, что проблемный файл или вложенная папка пропущены,
  а обработка остальных объектов продолжена.
- При следующем явном запуске ранее пропущенные файлы проверяются заново.

### Границы обработки ошибок

Недоступность выбранного диска или корневой папки целиком, сбой рабочей базы
и авария процесса остаются причинами незавершённого анализа. Пропуски файлов
сохраняются в журнале; завершение с 100% не означает отсутствие пропусков.

### Проверено

Повторная проверка на Windows 2026-10-29: сборка приложения и анализатора,
8 нативных тестов, 166 тестов Node и 35 тестов Python прошли. Ещё 3 теста Python
пропущены как неприменимые к Windows. Проверки использовали искусственные файлы.
Подробности и команды: [журнал проверок](docs/verification.md#пропуск-недоступных-файлов--повторная-проверка-2026-10-29).
